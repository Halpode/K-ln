# K-ln – Köln-Trip 08.–10.05.2026

Eine Geschenk-Webseite für einen 3-Tage-Trip nach Köln.

## 🌐 Live-Website

**[https://halpode.github.io/K-ln/](https://halpode.github.io/K-ln/)**

Der QR-Code auf der Seite verlinkt ebenfalls hierhin.

## Was ist das?

Eine einzelne HTML-Seite, die als Reiseführer und Geschenkkarte für einen Köln-Trip dient. Die Seite enthält:

- **3-Tage-Plan** (08.–10. Mai 2026) mit Timeline
- **ÖPNV-Übersicht** – KVB-Linien zur Kantine Köln (Pothead-Konzert)
- **Alle Links** – Kantine, Pothead, trashxchic, KVB, Airbnb
- **QR-Code** – direkt auf diese Seite

## Deployment

Die Seite wird automatisch über **GitHub Pages** aus dem Root-Verzeichnis des `main`-Branches bereitgestellt.

Unter *Settings → Pages → Source* die Option **„Deploy from a branch"** → Branch `main` → Ordner `/ (root)` wählen.
